# VerseShare marketing site

Next.js (static export) site for GitHub Pages: landing page, /support, /privacy.

## Run locally
    npm install
    npm run dev        # http://localhost:3000

## Edit before publishing
- `lib/site.js`: support email, App Store URL (once live), last-updated date.
